# 💼 BoundDesk CRM

**BoundDesk** is a modern, full-stack **Customer Relationship Management (CRM)** platform that helps teams manage leads, track activities, and collaborate in real time — all in one elegant dashboard.

Built using **React**, **Node.js**, and **PostgreSQL**, it combines performance, scalability, and a clean Neumorphic UI.

---

## 🚀 Tech Stack

| Layer | Technology |
|--------|-------------|
| **Frontend** | React.js, Styled Components (Neumorphic UI), Socket.io |
| **Backend** | Node.js, Express.js |
| **Database** | PostgreSQL (Render) via Prisma ORM |
| **Authentication** | JWT + Bcrypt |
| **Email Service** | Nodemailer (Gmail SMTP) |
| **Deployment** | Render (Backend) • Vercel (Frontend) |

---

## ⚙️ Key Features

- 🔐 **Authentication** – Secure login & signup with JWT  
- 💼 **Lead Management** – Create, filter, and manage leads with team and owner linkage  
- 🗓️ **Activity Tracking** – Log calls, meetings, chats, and enquiries  
- 📊 **Dashboard** – Overview of performance and CRM metrics  
- 🔔 **Notifications** – Real-time alerts using Socket.io  
- 👤 **Profile Management** – Update user details and roles  
- ✉️ **Email Integration** – Automated updates and follow-ups  
- ⚡ **Role-Based Access** – Admin, Manager, and Sales Executive hierarchy  

---

## 🧠 Modules Overview

| Module | Description |
|---------|-------------|
| **Dashboard** | Overview of CRM metrics and activity insights |
| **Leads** | Create, filter, and manage leads by team, status, or priority |
| **Activities** | Track all actions linked to a lead (Call, Email, Meeting, Chat) |
| **Notifications** | Real-time alerts via Socket.io |
| **Profile** | Edit user information (name, phone, email) |
| **Auth** | JWT-based login/signup for secure sessions |
